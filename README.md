# Сумрачный лес — Unity

Нативный прототип на C# и Unity 6 (6000.0, Built-in Render Pipeline). Браузерная версия не используется: игровой мир — Unity GameObjects и Mesh, интерфейс — Unity UI, звук — Unity AudioSource.

## Запуск

1. В Unity Hub выберите **Add → Add project from disk** и укажите папку `GroveSurvivorUnity`, содержащую `Assets`, `Packages` и `ProjectSettings`.
2. Откройте проект в **Unity 6.0 LTS**, исходная версия проекта — **6000.0.62f1**. Более свежий патч ветки 6000.0 также можно использовать после стандартного обновления проекта редактором. Установите модуль **Windows Build Support** для сборки Windows.
3. Дождитесь импорта пакета Unity UI. Откройте `Assets/Scenes/Main.unity` или меню **Grove Survivor → Открыть главную сцену**.
4. Нажмите **Play**. Главное меню, мир, камера и освещение создаются скриптами при запуске. Вне Play сцена содержит только объект запуска — это ожидаемо.
5. В окне Game выберите формат **16:9**, например **1600×900**. Основная целевая платформа этого проекта — Windows с клавиатурой и мышью.

## Что реализовано

- Главное меню, инструкция, настройки, пауза, результаты и перезапуск.
- Выбор мечника (всегда доступен) и трёх сложностей.
- Трёхмерная лесная поляна с видом сверху; движение WASD / стрелками.
- Автоматический разворот к ближайшей цели и удар мечом в секторе 150°.
- Зомби ближнего боя и скелеты со стрелами и предупреждением перед выстрелом.
- Выпадение и притягивание опыта, уровни, три случайно упорядоченных улучшения со случайной силой бонуса: урон, скорость атаки, здоровье.
- Выбор улучшения останавливает симуляцию. Бонусы складываются до завершения забега.
- Сложность влияет на HP, урон, размер волн и интервал появления. По времени растёт сила и количество врагов.
- Громкость, частицы, числа урона; настройки и рекорды через PlayerPrefs.
- Полноэкранный и оконный режим, выход из игры.

Esc / P — пауза. 1 / 2 / 3 — выбрать улучшение. Теряя фокус, игра автоматически ставит забег на паузу.

## Сборка Windows

В редакторе: **Grove Survivor → Собрать Windows x64**. Результат: `Builds/Windows/GroveSurvivor.exe` и сопутствующие файлы. Распространять нужно всю папку `Builds/Windows`, а не один EXE.

Из PowerShell с установленным редактором:

```powershell
& 'D:\Unity\Editor\6000.0.62f1\Editor\Unity.exe' -batchmode -quit -projectPath "$PWD" -executeMethod GroveSurvivor.Editor.GroveProject.BuildWindows -logFile build.log
```

Проект использует встроенную систему ввода `UnityEngine.Input`. Если открываете его в проекте с изменёнными настройками, в **Edit → Project Settings → Player → Active Input Handling** выберите **Input Manager (Old)** или **Both**. URP/HDRP не нужны.

## Структура

- `GameRules.cs` — параметры сложности, характеристики и формулы улучшений.
- `GroveGame.cs` — состояние игры, движение, бой, орды, опыт и сохранение.
- `ForestArt.cs` — процедурная геометрия леса, персонажей и эффектов.
- `GroveUI.cs` — меню, настройки, HUD и экраны забега.
- `Editor/GroveProject.cs` — конфигурация проекта и команда сборки.

## Ограничения прототипа и проверка

Unity 6000.0.62f1 установлен на машине создания. Импорт проекта, компиляция C# и сборка Windows x64 успешно выполнены настоящим редактором Unity. EXE создаётся в `Builds/Windows/GroveSurvivor.exe`; готовые бинарники не входят в репозиторий. Подробности проверки перечислены в `VALIDATION.md`.

## Совместная работа

Репозиторий: https://github.com/eggor130-lgtm/grove-survivor-unity . Исходники прототипа находятся в ветке `codex/unity-prototype`.

```text
git clone --branch codex/unity-prototype https://github.com/eggor130-lgtm/grove-survivor-unity.git
```

Репозиторий публичный: просмотр, скачивание ZIP и клонирование доступны без входа в GitHub. Откройте корневую папку клона через Unity Hub, дождитесь импорта и запустите сцену Main. Папки Library, Temp и Builds не хранятся в Git.

Графика схематичная, без внешних моделей и анимационных ассетов. Деревья — декорации, столкновения с ними не реализованы. Поляна имеет границы. Управление на телефоне в этой Unity-версии пока не реализовано. Забег и улучшения не сохраняются между запусками; сохраняются настройки и рекорды.
